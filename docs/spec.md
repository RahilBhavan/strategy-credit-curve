# Scope and acceptance

Purpose: preserve the implemented v1 while making an independently reproducible public research tool.

Compare STRF, STRC, STRE, STRK and STRD by currency, seniority, dividend accumulation and conversion rights. Price six sourced convertible schedules on a TF tree under explicit volatility/spread scenarios. Reconcile the August 2024 10:1 split; validate analytic limits and convergence; disclose embedded-option, FX and contract-calendar approximations. This is a comparison, not a fitted credit term structure or a causal estimate of a noncumulative premium.

The public demo has five preferred rows and six nine-scenario note grids, all offline. Financial terms and the bundled rates are frozen to October 21, 2026; the October 28 vote is pending at that cutoff. Later valuation dates require a user-supplied rates file and keep the October 21 terms. Public stock prices and STRK option volatilities are labeled synthetic assumptions. A schema-v1 file supports user-supplied inputs and preserves observation/retrieval provenance without bundling restricted provider bodies.

The user explicitly authorized public GitHub publication and a clean sanitized publication snapshot. The complete original local history and cache remain private and intact. The public history starts separately, contains reviewed source and appropriate attributed SEC/government data, and includes no full Nasdaq/Cboe/Yahoo responses in any ancestor. No UI, web deployment, license choice, scheduled service or trading action is part of this project.
